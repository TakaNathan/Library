Ce projet est une librairie Python qui permet de stocker et de gérer des données localement. Au lieu d'utiliser un système de gestion de base de données lourd (comme SQLite ou PostgreSQL), cette librairie utilise un simple fichier CSV (Comma-Separated Values).C'est la solution idéale pour les petits projets, les scripts d'automatisation ou les prototypes nécessitant une persistance des données sans configuration complexe.

Fonctionnalités :
   -Zéro configuration : Pas de serveur      à installer, un simple fichier CSV  suffit.
   -Lecture/Écriture simplifiée : Fonctions intuitives pour ajouter, modifier ou supprimer des lignes.
   -Haute portabilité : Le fichier CSV généré peut être ouvert directement dans Excel ou LibreOffice.
   -Légèreté : Écrit en Python pur, sans dépendances lourdes.
